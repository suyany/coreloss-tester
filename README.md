# Core-Loss Tester

Automated core-loss measurement for ferrite magnetics under non-sinusoidal
(PWM-like) excitation, 100 kHz–1 MHz — the gap named in Anderson & Ranjram,
COMPEL 2023 ("no method has been demonstrated in the literature for
automated core loss collection at greater than 1 MHz").

**Status: Phase 0 (feasibility).** Testing whether the available
measurement chain (scope, probes, function generator) can resolve the
phase error this measurement needs, before any hardware is built. Nothing
here is validated yet; no core has been driven.

Running state is in `worklog.md`, committed weekly, dead ends included.
